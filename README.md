# Salary Analysis Dashboard — Power BI

## О проекте
Учебный проект по анализу заработной платы сотрудников с использованием Power BI.

## Цель
Анализ фонда оплаты труда, отработанных часов и стоимости рабочего часа, а также выявление отклонений от нормы рабочего времени.

## Ключевые показатели
- Фонд оплаты труда (ФОТ)
- Отработанные часы
- Стоимость часа
- Отклонение от нормы рабочего времени
- Топ сотрудников по начислениям

## Инструменты
- Power BI Desktop
- Power Query
- DAX
- Excel

## Функциональность
- Фильтрация по году и месяцу
- Фильтрация по сотруднику
- Динамика ФОТ по месяцам
- Структура ФОТ по отделам
- Сравнение начислений сотрудников
